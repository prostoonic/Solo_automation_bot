# Solo_automation_bot
# Соло на клавиатуре Bot

Автоматизация прохождения уроков в тренажёре «Соло на клавиатуре» с использованием Python, Tkinter и PyAutoGUI.

## Возможности

* Загрузка уроков из XML-файла.
* Выбор урока через GUI.
* Настройка скорости набора в CPM.
* Настройка вероятности ошибок.
* Автоматический ввод текста через PyAutoGUI.
* Имитация случайных ошибок с последующим исправлением.
* Отображение текущего статуса и прогресса.
* Счётчик введённых символов и ошибок.
* Работа бота в отдельном потоке без зависания интерфейса.
* Безопасная остановка через кнопку «Стоп».
* Аварийная остановка через `PyAutoGUI FAILSAFE`.

## Требования

* Python 3.11+
* Windows 10/11
* Русская раскладка клавиатуры
* XML-файл с упражнениями
* PyAutoGUI
* pyperclip

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/prostoonic/Solo_automation_bot
cd Solo_automation_bot
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Поместите XML-файл с упражнениями в корень проекта.

По умолчанию программа ожидает файл:

```text
126_00020202.xml16.xml
```

Путь к XML можно изменить в `config.py`.

## Запуск

```bash
python main.py
```

## Использование

1. Запустите приложение.
2. Выберите нужный урок.
3. Укажите скорость набора в CPM.
4. Укажите вероятность ошибок в процентах.
5. Нажмите **«Старт»**.
6. В течение 3 секунд переключитесь на окно «Соло на клавиатуре».
7. Бот начнёт ввод текста.
8. Для остановки нажмите **«Стоп»** или переместите курсор в левый верхний угол экрана.

## XML

Программа загружает упражнения из XML-файла.

Основные атрибуты `<exercise>`:

| Атрибут      | Описание                     |
| ------------ | ---------------------------- |
| `lesson`     | Номер урока                  |
| `number`     | Номер задания                |
| `errors`     | Допустимое количество ошибок |
| `type`       | Тип упражнения               |
| `speed`      | Скорость                     |
| `difficulty` | Сложность                    |
| `lowspeed`   | Минимальная скорость         |
| `highspeed`  | Максимальная скорость        |
